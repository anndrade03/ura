Como funciona

Tudo o que você altera aqui aparece na hora no site aberto neste mesmo navegador.

  1. Faça as alterações nas seções do menu ao lado. Tudo é salvo automaticamente.
  2. Clique em Ver site para conferir como ficou.
  3. Em Publicar e backup, baixe o arquivo dados.json e envie para o GitHub junto com o site para todos os visitantes verem as mudanças.

Publicar e backup

Leve as alterações para o site no ar e guarde cópias de segurança.

Publicar no site

As alterações ficam salvas neste navegador. Para todos os visitantes verem:

  1. Clique em Baixar dados.json.
  2. No repositório do site no GitHub, envie o arquivo dados.json (substituindo o anterior, se houver), na mesma pasta do index.html.
  3. Aguarde de 1 a 2 minutos e atualize o site.

Backup completo

Inclui também a lista de revendedores (que não vai para o dados.json público).
